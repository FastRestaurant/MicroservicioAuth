<div align="center">
  <h1>🔐 Microservicio de Autenticación</h1>
  <h3> Encargado de la seguridad y el control de acceso a la plataforma. </h3>
</div>

* **Gestión de Usuarios:** Registro, actualización y eliminación de cuentas.
* **Autenticación y Autorización:** Inicio de sesión (Login) y validación de credenciales.
* **Gestión de Tokens:** Emisión de **JWT (JSON Web Tokens)** para proteger los endpoints y manejo de *Refresh Tokens* para mantener las sesiones activas de forma segura.
* **Roles:** Asignación y verificación de roles de usuario (ej. Administrador, Cocinero, Camarero) para restringir el acceso a funcionalidades específicas.
